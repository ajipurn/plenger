## How a review works

1. **Read the repository.** The static engine reads files, builds an inventory
   and traces capabilities. It never runs project code.
2. **Discover candidates.** The selected model reviews bounded, redacted source
   and considers all six STRIDE categories.
3. **Validate the evidence.** A second review checks candidates against source.
   You can select a separate model connection for validation.
4. **Decide what to fix.** Inspect locations, evidence and remediation. Generate
   a prompt to take into your coding agent.

## Your source and your connection

Projects, results and credentials are stored locally. Source leaves the machine
for the provider you select, after redaction. AI review consumes that connection's
usage. The static engine runs offline.

Read the [architecture](/docs/architecture/) for the source layout, or
[contributing guide](/docs/contributing/) to work on Plenger.
