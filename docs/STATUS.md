| Static scan of Python, JavaScript and TypeScript | Available | Inventory, capabilities, 38 risk rules, seven of them for request input in web routes (FastAPI, Flask, Django, Starlette, aiohttp, Express, Fastify, Hono, Koa, NestJS, Next.js) reaching a command, a file path, SQL text, a URL's host, code, a template or a deserializer across modules; never executes project code. Checks before an effect are read: fixed allowlists, equality, lookups into fixed tables and host allowlists, and for file paths name patterns, `..` checks with `/` or absolute-path checks, and resolved paths kept inside a base, also when a project function returns the path after that check or is a check helper that returns true only for a confined path. File names with no separators that are never `.` or `..` (`secure_filename`, a name with fixed text), and absolute paths among program arguments, carry nothing. `plenger-ignore` comments suppress findings in the source. JSX that the JavaScript grammar rejects is parsed again; larger projects parse on worker threads. Calls through fixed tables of functions, pathlib joins and methods on parenthesized expressions are followed, and a project's own tool base classes are detected. Handler traces cut by the depth limit or dynamic calls are reported. Compiled files are listed with size and SHA-256, not analysed. The scan engine's `library: true` option counts the parameters of a package's public functions and methods as untrusted input, reported by seven more rules at medium or low confidence; a path or URL whose start the caller passes is not reported. ## npm distribution

npm is the primary installation method. The CLI starts the dashboard with
`plenger` and provides help, version and confirmed `plenger update`.
Users need Node.js 22.23.4+, 24.22.1+ or 26.12.1+, the patches that fix the
Brotli flaw CVE-2026-111497. The installed dashboard uses its built frontend.
The former analysis and red-team commands are removed; their engines remain.

| Entry | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| plenger | Dashboard stopped normally, help or version printed | Startup or shutdown failed | Invalid launcher options | Not used |
| plenger update | Updated, current, or confirmation declined | Registry, npm, verification failure or private build | Unsupported installation or missing interactive confirmation | Not used |
